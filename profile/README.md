### What I build

Production agentic AI and cloud platform systems — auth, queues, telemetry, dashboards, approvals, and the failure handling that keeps them running. Mostly AWS serverless, Python, and Terraform. I run [@zerodaysec](https://github.com/zerodaysec) and a k3s homelab that exists mainly so I can break things safely.
